# サイトマップ / ページ設計

参考: yz-store.com/collections/9090 のコレクションページ／商品詳細ページの構成。
配色・タイポは Balenciaga 公式寄りのミニマル・モノトーン。

## ルート一覧

| パス | 内容 | 認証 |
|---|---|---|
| `/` | トップ（ブランドコンセプト・ストーリー＋カテゴリごとの全商品） | 公開 |
| `/products/[slug]` | 商品詳細 | 公開 |
| `/cart` | カート | 公開 |
| `/checkout` | 配送先入力・注文確認（決済ステップなし） | 要ログイン |
| `/checkout/complete` | 注文完了 | 要ログイン |
| `/login` | ログイン | 公開 |
| `/register` | 会員登録 | 公開 |
| `/account` | マイページ ダッシュボード | 要ログイン |
| `/account/orders` | 注文履歴 | 要ログイン |
| `/account/orders/[number]` | 注文詳細 | 要ログイン |
| `/account/addresses` | 住所録（一覧・追加・編集・削除・デフォルト設定） | 要ログイン |
| `/account/profile` | 氏名・メール・パスワード変更 | 要ログイン |
| `/admin/**` | 管理者ページ（詳細は `docs/05-admin.md`） | 要 admin |

ブランド紹介は独立ページを持たず `/` トップページ内のセクションとして統合する（軽いコンセプト紹介程度のボリュームのため。R1 で決定）。

カテゴリ別一覧（`/collections/[category]`）、および全商品一覧（`/collections`）自体も作らない。大規模なECではなく、カテゴリ1つあたり3〜6点程度の小規模カタログなので、`/` トップページのカテゴリごとのセクションで全商品を出し切れば十分と判断（R1 で決定）。商品ブラウズは `/` の中で完結する。

未ログインで要ログインページに来たら `/login?redirect=<元パス>` に転送。
`/admin/*` は `middleware.ts` で `role === 'admin'` を確認、非 admin は `/` へ。

## 共通レイアウト

### ヘッダー
- 左: `EC-PORTFOLIO` ロゴ（`/` へ）
- 中央: 無し（`SHOP`・`ABOUT`とも置かない。カテゴリ数・商品数が少なくナビの必要性が薄いため。商品ブラウズは `/` トップページ内で完結する。R1 で決定）
- 右: `ACCOUNT`（未ログイン時 `/login`、ログイン時 `/account`）/ `CART (n)`（検索機能は今回無し）
- 常に白背景・下ボーダー固定（透過は無し。全ページ共通。R1 で決定）
- 項目が少ない（ロゴ＋ACCOUNT/CARTのみ）ため、モバイルもハンバーガーメニューにせず同じ1行のバーをそのまま使う

### フッター
- ニュースレター入力（ダミー、送信でトースト表示のみ）
- リンク: `Shipping` `Returns` `Privacy` `Terms`（静的プレースホルダ）
- `© 2026 EC-PORTFOLIO. All rights reserved.`

## 各ページ

### `/` トップ
1. フルスクリーンのヒーロー画像＋中央に小さくブランド名とタグライン
2. ブランドコンセプト文（3〜4行、余白広め、中央寄せ）。**理念・スタンスのみ**を短く語る
3. ルックブックの横スクロール帯（画像のみ 5〜6枚）
4. カテゴリごとの商品セクション（`TOPS` `BOTTOMS` `OUTERWEAR` `ACCESSORIES` の順）: カテゴリ名の極太見出し＋そのカテゴリの**全公開商品**を`position`順にグリッド表示（`/collections`を作らないため、先頭N点に絞らず全件をここで出し切る。R1 で決定）
5. `ABOUT` セクション（旧`/about`を統合）: **沿革・素材へのこだわり・製造背景**のプレースホルダ文＋画像数枚。静的。項目2（コンセプト）とは役割を分け、ここでは理念を繰り返さず「歴史・背景」を語る（R1 で決定）

商品グリッド: PC 4カラム / タブレット 3 / モバイル 2。商品カード（yz参照）:
- 画像（`position=0`）、ホバーで `position=1` に差し替え
- 左上バッジ: `NEW`（作成30日以内）/ 在庫バッジ `LOW STOCK`・`SOLD OUT`
- カテゴリ名 or ブランド表記（小・グレー・全大文字）
- 商品名（最大2行）
- 価格 `¥12,000`

並び順は `products.position`。ソートUIは無し。カテゴリに商品0件時はそのセクション自体を出さない。

### `/products/[slug]` 商品詳細（yz参照）
- パンくず: `HOME / 商品名`
- 左: 画像ギャラリー（全画像を縦積み）。モバイルは横スワイプカルーセル＋ドット
- 右: スティッキーパネル
  - カテゴリ（小・グレー・全大文字）
  - 商品名 / 価格
  - 配送目安の囲み（`SHIPPING: 3–5 BUSINESS DAYS`、静的）
  - 色スウォッチ（複数色ある商品のみ。選択で画像・在庫を切替）
  - サイズセレクタ（`product_variants`。`stock=0` はグレーアウトかつ選択不可、`残りわずか` はサイズ横に小さく `LOW STOCK`）
  - `ADD TO CART`（サイズ未選択時は非活性）→ 追加でカートドロワー or トースト
  - アコーディオン:
    - `DESCRIPTION` … `description`
    - `MATERIAL & CARE` … `material` ＋ `care`
    - `SIZE GUIDE` … `size_chart` を表でレンダリング（null のカテゴリは非表示）
    - `SHIPPING & RETURNS` … 静的
  - スペック（アコーディオン外に小さく）: `ORIGIN` `origin` / `PRODUCT CODE` `product_code`
- 下部: `YOU MAY ALSO LIKE` — 同カテゴリの他の公開商品を position 順に全件（件数上限なし。カテゴリ1つあたり3〜6点のため）

### `/cart` カート
- 明細行: サムネ / 商品名・サイズ（・色）/ 単価 / 数量ステッパー / 小計 / 削除
- 数量上限は当該 variant の `stock`
- 右（PC）/ 下（モバイル）にサマリー: `SUBTOTAL` / `SHIPPING` / `TOTAL` / `CHECKOUT` ボタン
- 空カート: `YOUR CART IS EMPTY` ＋ `CONTINUE SHOPPING`
- カートは Zustand + localStorage。ヘッダーの `CART (n)` と同期
- ページ表示時に各明細の商品/在庫/価格を API で再検証（売り切れ・価格変動を反映）

### `/checkout` チェックアウト（決済なし）
1. 配送先: 住所録から選択、または新規入力（「住所録に保存」チェック）
2. 注文内容の確認（明細・送料・合計）
3. `PLACE ORDER` → `POST /api/orders` → `/checkout/complete`
- 決済手段の選択・入力は無し。注文は `status = pending` で作成

### `/checkout/complete` 注文完了
- `注文番号` 表示、`VIEW ORDER`（注文詳細へ）、`CONTINUE SHOPPING`
- カートを空にする

### `/login` / `/register`
- ミニマルなフォーム（メール・パスワード、登録時は氏名も）
- 成功で `redirect` パラメータ先、無ければ `/account`
- バリデーションエラーはフィールド下に表示

### `/account` ダッシュボード
- `ようこそ, {name}`
- `ORDERS` / `ADDRESSES` / `PROFILE` / `LOGOUT` のメニュー（admin なら `ADMIN PANEL` も）
- ※「直近の注文1件のサマリー」は当初案にあったが、注文一覧（`/account/orders`）に行けば見れる重複なので削除した

### `/account/orders` 注文履歴
- 一覧: 注文番号 / 日付 / 点数 / 合計 / ステータス
- 行クリックで `/account/orders/[number]`

### `/account/orders/[number]` 注文詳細
- 配送先スナップショット / 明細 / 送料 / 合計 / ステータス / 注文日時

### `/account/addresses` 住所録
- カード一覧（デフォルトにバッジ）
- 追加・編集（別ページ or モーダル）、削除、デフォルト設定
- 項目: 宛名 / 郵便番号 / 都道府県 / 市区町村 / 番地 / 建物（任意）/ 電話番号

### `/account/profile` プロフィール
- 氏名・メール変更フォーム
- パスワード変更フォーム（現パスワード必須）

## 業務ルール

- 送料: 一律 ¥800、小計 ¥20,000 以上で無料
- 価格・金額はすべて整数（JPY・税込）
- 在庫: 注文時に `stock` を減算（トランザクション内）。不足時は 422 で明細を返す
- 在庫ステータス: `0`→SOLD OUT / `1〜3`→LOW STOCK / `4以上`→在庫あり（`LOW_STOCK_THRESHOLD = 3`）
- `NEW` バッジ: `created_at` が 30 日以内
